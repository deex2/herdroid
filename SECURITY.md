# Security policy

## Supported versions

Security fixes target the latest source on the repository's default branch.
Older builds are not maintained separately while Herdroid is in active development.

## Report a vulnerability

Do not open a public issue. Use GitHub's **Security → Report a vulnerability**
flow to send a private report. If private reporting is unavailable, contact the
repository owner privately before sharing technical details.

Include the affected commit or version, impact, reproduction steps, and a
minimal proof of concept. Remove credentials, private keys, host keys, private
addresses, and unrelated logs.

SSH authentication, host-key verification, bridge integrity, terminal access,
and accidental secret exposure are all in scope.
